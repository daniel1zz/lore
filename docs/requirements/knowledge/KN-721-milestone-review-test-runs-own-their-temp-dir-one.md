| concurrency_safety | pass | Concurrent runs cannot corrupt each other. Each run gets a unique root from mkdtemp, keyed by its own pid. The sweep removes only roots whose pid returns ESRCH, so a live run's root is never touched; the oracle checks this with a live armed run alongside a vitest run. A root created after another run's sweep belongs to a live pid. Two runs sweeping the same dead root at once are harmless because rmSync uses force:true. mkdirSync recursive is idempotent. Remaining edge cases cost space, not correctness. Pid reuse keeps a dead root until the reused pid exits. Separate pid namespaces sharing one temp dir, such as containers sharing /tmp, could see a live run as ESRCH, but that setup does not apply to the per-user macOS temp dir in this repo. | scripts/test-isolation-env.ts removeDeadRunRoots/isPidGone/createRunRoot; oracle case 'a root whose pid is alive is kept by another run' |
