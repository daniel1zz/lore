| concurrency_safety | pass | Concurrent runs get distinct roots from mkdtemp(<pid>-XXXXXX). The sweep in removeDeadRunRoots skips any root whose pid is alive, and a pid owned by another user (EPERM) also counts as alive, so one run never deletes a live run's root. The oracle checks this with a live run alongside a concurrent run. mkdirSync(recursive) on the shared lore-test-runs/ is idempotent, and rmSync(force) tolerates two runs sweeping the same dead root. Remaining weaknesses: (a) if a dead run's pid is reused, its root is kept, which is a leak and not corruption; (b) a pid namespace that shares the temp dir, such as a container mounting the host /tmp, could make a live run look gone. (b) does not apply to the per-user macOS DARWIN_USER_TEMP_DIR this targets. Nested runs register no exit handler, so they never remove their parent's root. | scripts/test-isolation-env.ts isPidGone/removeDeadRunRoots; test 'a root whose pid is alive is kept by another run' |
| security | pass | No credentials, network input or privilege change is involved.
