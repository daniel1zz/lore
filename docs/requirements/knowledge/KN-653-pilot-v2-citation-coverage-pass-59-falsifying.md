# Pilot v2: citation coverage pass and content fixes (tasks V1b, V1c)

Plan `plan-baseline-pilot-v2-migration-method-v2-on-the-specification`. Executed 2026-10-08 from main by agent:main-orchestrator; the rule-by-rule analysis was done read-only by two independent agents (leaves split 4/4), each citation required a specific test whose assertion fails if the rule is false (file:line + title in the table). All 30 distinct cited ACs were then machine-checked: live spec (approved|active), verify mode script — 0 failures.

## Outcome
- 95 rules analysed: 89 agree with code, 6 contradicted (BR-5, BR-11, BR-63, BR-71, BR-74, BR-90) — statements corrected to match code.
- 5 v1 citations withdrawn because their AC cannot falsify the cited rule (topic placement, the v1 failure mode): AC-FR-11→BR-51, AC-FR-12→BR-51, AC-ACS-10→BR-31, AC-ACODE-3→BR-15, AC-ACODE-9→BR-25.
- 59 citations added on 25 ACs. Afterwards: 55 rules cited by >= 1 falsifying script-mode AC; 47 of them already have passing attested evidence.
- 32 established/observed rules had no falsifying AC → downgraded to unconfirmed, each with an open question appended to its leaf. 28 of the 32 were observed (the excavation's own "intent not confirmed" class); 4 were established (BR-12, BR-31, BR-34, BR-51 — counted from the generator's down list).
- BR-73 reworded for clarity only (it was never wrong — see the Correction in `knowledge-pilot-assessment-baseline-slice-1-specification`); BR-21 and BR-36 relabelled enforced-by guaranteed (the CLI always runs the missing-test-file check).
- New BR-96 (declare leaf): any digit anywhere counts as a measurable anchor — promoted from the glossary; unconfirmed because no AC isolates it (every positive lint fixture also carries a sign/unit).
- `lore status` after: rules_total 96, contradicted 0, passing_staleness_unchecked 47, unverified 49, rules_uncovered 41 (= 32 downgraded + 5 unconfirmed + 3 undecided + BR-96), acs_citing 31.

## Findings worth keeping
- The wording-lint refusal at declare/create/approve has no live AC: its tests (`ac-quantifiable-gate.test.ts`, `gate-spec-create.bun.test.ts`) belong to a spec still in draft, so BR-5/BR-74 cannot be cited.
- Root CLAUDE.md says editing an approved doc's `extra` demotes it; code demotes on content/title only (BR-80/BR-81 match code). Reported separately as an issue, not fixed here.
