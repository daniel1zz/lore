| concurrency_safety | pass | Each root's name carries its creator's pid, and a run removes only roots whose pid lookup gives ESRCH, so concurrent live runs never delete each other's roots. The oracle checks this with a live armed process during a vitest run. If two runs remove the same dead root at once, both call rmSync with force:true and the second is a no-op. mkdirSync with recursive:true on the shared lore-test-runs/ is idempotent, and mkdtemp gives unique names. If a pid is reused, a dead root is kept rather than deleted, which is the safe direction. Remaining edge: when the main process is SIGKILLed, orphaned forked workers or children can briefly keep writing into a root that the next run then removes. Their owner is gone, so no live run's state is lost. | kill(2) ESRCH vs EPERM semantics; scripts/test-isolation-env.ts removeDeadRunRoots; oracle case 'a root whose pid is alive is kept' |
| security | fail | Before this change, mkdtemp ran directly in tmpdir(): a fresh 0700 directory, protected by the sticky bit when tmpdir() is /tmp. The code now places every run under a fixed, predictable shared name, <tmpdir>/lore-test-runs, using mkdirSync with recursive:true and no check of owner or mode. On macOS the per-user DARWIN_USER_TEMP_DIR makes this harmless. On Linux, which the plan covers ('os.tmpdir() on other platforms'), tmpdir() is the shared /tmp. Another local user can pre-create /tmp/lore-test-runs with mode 0777. They can then rename the victim's 0700 <pid>-XXXXXX root and put a symlink to a directory they control in its place. The run keeps using the fixed HOME/TMPDIR strings, so the test HOME (.gitconfig, any tokens or config that tests write) and the temp files land in the attacker's directory. Exit cleanup then removes only the symlink. The same pre-created directory also lets that user make every test run fail when mkdtemp is refused. Fix: after creating lore-test-runs, lstat it and refuse unless it is a real directory owned by the current uid with mode 0700, or create it with mkdtemp/0700 and verify it. | CWE-377 Insecure Temporary File / CWE-379; scripts/test-isolation-env.ts createRunRoot (mkdirSync(runRootsDir, {recursive:true})) |
