# Architecture debt

The gap between the current state and the standards. Each debt entry is an AD-n on the debt registry below and names the open issue that tracks it. Existing debt may stay; new or enlarged debt is forbidden. A standard lists the AD-n entries that except it under Current Exceptions; an entry closes when its issue resolves and the standard's exception list drops it.
