## Overview

Implements `spec-lore-owned-agent-context-is-generated-from-templates-and` (AC-CV-1 … AC-CV-8): a `{{lore:<name>}}` expander in `@lore/core` with an injectable registry assembled in `packages/lore`, applied at every lore-owned outlet (fragment rules/skills/subagent-start, installed skills/agents/hooks, settings-hook claude dir), a literal-duplication lint, and removal of hand-typed tool counts (fixes #209).

## Invariants

- I1 No silent fallback: an unregistered / disallowed / unresolved `{{lore:…}}` fails loud with file:line; no rendered or installed file contains `{{lore:`.
- I2 Non-`lore:` double braces (`{{file_list}}`, `{{input}}`, `{{ACTOR}}` in seat-briefing) are byte-preserved.
- I3 Project outlets depend only on the lore version: byte-identical across HOME / global config (BR-902, BR-1096).
- I4 Fragments without `{{lore:` render byte-identical to before.
- I5 `bun scripts/embed-assets-manifest.mjs --check` exits 0 on main after every merge; manifest is regenerated by the script, never hand-merged.
- I6 Tests never touch this repo's `.lore/` and never call the installed `lore` — they spawn `bun packages/lore/src/index.ts` with `HOME=<mkdtemp>`.

## Decisions Log

- Strategy: Interface-First, Dependency-Ordered — chosen. Rejected: vertical slices per outlet (each waits on the expander; no gain), horizontal layers (serializes unrelated outlets).
- Research gate: templating libraries (Handlebars / Mustache / Eta) REJECTED — one namespaced token with fail-loud lookup, no logic; Mustache-style `{{x}}` would capture LLM prompt slots (I2).
- S3 bundle review (3 lenses) changed the design:
  - Config-sourced variables dropped — `.lore/config.yaml` is gitignored, so project-config values would break BR-902 byte identity; no user-scope enforced setting exists. Configurability stays at fragment level (selection / disable / language).
  - Seat briefing out of scope — BR-851 / AC-CF-17 require byte-for-byte output; its values are per-session, not duplicated facts.
  - CLAUDE.md code facts are DELETED, not generated — the approved content contract puts code-derivable facts OUT of memory files; generating a Z1 section would also collide with the required `## Module Index` and the existing `auto:module-index` block.
  - Installed assets expand in `RealAssetSource.load()` (setup copies raw files; the manifest stores only hashes), and the manifest script hashes through the same expander.
  - Registry split: core = mechanism + core-owned constants; lore = registry instance (avoids core → lore cycle); registry injected everywhere.
- `CAPTURE_TAIL_CHARS` moves to `@lore/core`.
