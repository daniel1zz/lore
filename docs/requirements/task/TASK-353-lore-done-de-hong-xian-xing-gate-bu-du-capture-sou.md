来源：knowledge-lore-gong-ju-ji-zhi-guan-cha-run6-pi-shi-ce-hong-xian（guyin 项目 corpus） 第 1 条。红先行是整套防假绿机制的地基；若它可被一段文本满足，则「已归档」不等于「测试真的红过」。值得注意的是抓到它的是 advisory 的 lore assess（判词：13/14 是转录、7% 验证率），不是确定性 gate —— 这反转了 lore 自身「确定性 gate 拦截 / AI judge 仅 advisory」的信任模型。
