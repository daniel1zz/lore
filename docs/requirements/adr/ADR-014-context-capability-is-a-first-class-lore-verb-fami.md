# ADR: Context capability is a first-class lore verb family — lore-init-context skill retired, CLAUDE.md becomes two-zone (projected + admission-controlled)

## Status
Accepted (spec landed and fully verified 2026-07-27: spec-context-verb-family-two-zone-claude-md-anatomy-lore, 7/7 attested ACs)

## Context
Owner set three invariants for the resident context file: (1) explicit admission control — what may enter CLAUDE.md and what may not; (2) it must track code reality, not stay frozen; (3) it is RESIDENT INJECTION, not memory — events/status/history belong to the corpus. Today the generation/refresh capability lives in a skill (lore-init-context): a prompt package, untestable, unversioned relative to the binary, model-compliance-dependent — while ~80% of its work (structure scan, module detection, drift detection, file writes) is deterministic. The project has already verb-ized three prose/skill surfaces (SPEC-083 governance, SPEC-085 seat-briefing, SPEC-070 task-feed derivation).

## Decision (direction)
- CLAUDE.md anatomy: two zones. Z1 = lore-managed marker sections regenerated by a new idempotent verb (module index with existence-checked links, command table, governance/spec pointers) — pure projections of reality, drift structurally impossible (SPEC-081 projection precedent, SPEC-076 D7 marker + five-state diverged-skip reused). Z2 = hand-written standing discipline, admission-controlled by deterministic lint (lines/bytes ceilings — existing; reference-existence checks — new, same shape as code_anchors file_missing) plus ADVISORY dated-narrative/status-word detection (gate-deterministic / judge-advisory split preserved).
- Verb family: lore context init (first generation; AI narrative via existing provider seam, provider-absent degrades to skeleton + loud warning) / lore context refresh (idempotent Z1 regeneration) / extended lore status --check-claude-md (reference existence).
- Enforcement surfaces: refresh verb + pre-push (existing) + edit-time PostToolUse hook (zero numbers in hook; delegates to --check-claude-md).
- lore-init-context skill retired via RETIRED_FROM_INSTALL_PATHS once verbs land.
- Numbers stay solely in context.memory_files.* config (D1 of the content-contract spec); this repo dogfoods tightened budgets (root 220L/24576B).

## Consequences
- The flagship context capability moves inside the tested, gated, distributed binary with AC-as-code coverage; consumer projects get it via normal binary upgrade, no skill install.
- Supersets (does not conflict with) spec-project-claude-md-content-contract; in-flight Phase 2/3 work is reused as-is.
- Next step: PRD outline entry + tech-spec via the design workflow, then implementation plan. This ADR records direction only.
