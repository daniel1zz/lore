# Module: @lore/dashboard

## Purpose

Local-development web UI for browsing the Lore corpus. Vite + React 19 + TypeScript + Tailwind v4 + shadcn/ui. **Read-only v1** per SPEC-015: list / search / tree / detail. No auth, no write paths.

## Local-dev topology

```
Terminal A          Terminal B                   Browser
──────────          ──────────                   ───────
bun run dev         bun run --filter             http://localhost:5173
→ lore serve          '@lore/dashboard' dev          │
→ :8787             → vite :5173 ◄──────────────────┘
                       └── proxy /api/* ──► localhost:8787
```

Two-process model intentional. `vite.config.ts` sets `server.proxy: { "/api": "http://localhost:8787" }` so the browser sees one origin (no CORS).

## Key Invariants

- **Read-only.** Dashboard never calls write endpoints. No POST/PATCH/DELETE in `src/lib/api.ts`. Adding mutations belongs in SPEC-017 — do not pre-empt.
- **No auth state.** Dashboard ships without login. SPEC-016 will add cookie/session — until then, `lore serve` accepts the dashboard's requests via the same bearer token configured for the user's local API key (forwarded by the dev proxy if needed).
- **Depends on `@lore/core` only.** `packages/dashboard/package.json` MUST NOT depend on `@lore/lore`. All server interaction goes through HTTP. Boundary check: `grep -r 'from "@lore/lore"' src/ → 0`.
- **No server-side modules in `src/`.** No `bun:sqlite`, `child_process`, `node:fs`, or any other Node-side built-in. Dashboard is a browser app. Boundary check: `grep -rE 'bun:sqlite|child_process|node:fs' src/ → 0`.
- **TanStack Router file-routing.** Five route files under `src/routes/`. `routeTree.gen.ts` is git-ignored and regenerated by the Vite plugin on dev start + the `prebuild` script. Don't commit it.
- **All client state is server state (TanStack Query) + URL state (router).** No Zustand / Jotai / Redux even "to set up". When state appears stateful, ask: is this query cache or a query param? It should be one of those.

## Patterns

- **`src/lib/api.ts`** — typed fetch wrapper returning `Result<T, ApiError>`. 5-second `AbortController` timeout. Normalises errors to `{ code, message }`. All route handlers call this; nothing else touches `fetch`.
- **TanStack Query hooks** — `useSuspenseQuery` + `<Suspense>` boundaries for loading; `<Skeleton/>` from shadcn for shimmer.
- **Component primitives** — shadcn under `src/components/ui/` (button / card / input / table / badge / scroll-area / separator / skeleton / dropdown-menu / sonner). Compose into feature components (`DocCard`, `DocDetail`, etc.) under `src/components/`.
- **Theme** — `useTheme()` reads localStorage `theme` and applies `dark` class to `documentElement`. Tri-state: light / dark / system.

## Tests

- vitest with `environment: "jsdom"` (set in `vite.config.ts` test block).
- Component tests use `@testing-library/react` + `user-event`.
- `tests/setup.ts` imports `@testing-library/jest-dom/vitest`.
- 6-dimension coverage (HAPPY / NEGATIVE / BOUNDARY / ERROR / STATE / REGRESSION) for `api.ts`; behavioural for components.
- No E2E (Playwright/Cypress) until SPEC-016 adds auth flow worth E2E-ing.
