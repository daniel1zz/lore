# Product Wisdom: Quick Reference

> Pattern recognition triggers and decision heuristics — not full explanations.

## Success Pattern Checks

| Pattern | Strong Signal | Weak Signal | Action if Weak |
|---------|--------------|-------------|----------------|
| Hair-on-fire problem | Users building workarounds, willing to pay pre-product | "That would be nice" | Validate harder |
| Single player mode | ONE user gets value with ZERO others | Value depends on "when everyone uses it" | Build standalone value first |
| Do things that don't scale | Manually onboarding, calling churned users | Premature automation | Manual first → learn → automate |
| Minimal viable experience | Perfect ONE use case | Half-built everything | Focus on one complete experience |

## Failure Mode Detectors

| Mode | Signals | Response |
|------|---------|----------|
| Building for yourself | "I would use this", "don't need research" | You are not your user. Seek disconfirming evidence. |
| Feature creep | "Competitor has X", "can't remove anything" | Say no by default. Strengthens core value prop? |
| Premature scaling | Hiring sales pre-repeatable process, ads pre-retention | Check PMF: organic growth, flat retention, user referrals |
| Competitor obsession | Competitive grid drives roadmap | Would we build this if competitor didn't exist? |
| Build trap | Success = features shipped, no impact measurement | Tie roadmap to outcomes. Measure usage. |
| Big bang launch | Months without feedback, "can't show until perfect" | Launch early to small audience, iterate, then scale |
| Happy ear | "Interesting", users say they'd use it (but haven't) | Look for actions not words. Strong = ask when they can buy. |

## Decision Heuristics

| Tool | Key Question | Use For |
|------|-------------|---------|
| Reversibility | Type 1 (irreversible) → slow; Type 2 (reversible) → fast | Common mistake: treating Type 2 as Type 1 |
| 10/10/10 | How will I feel in 10 min / 10 months / 10 years? | Short-term discomfort overweighting |
| Newspaper test | Would I be proud if this was public? | Ethics, privacy, pricing |
| Regret minimization | At 80, will I regret not trying? | Big irreversible strategic decisions only |

## Conversation Anchors
- **Andreessen**: Market > product. Great product in bad market = failure.
- **Cagan**: Best teams get problems, not features.
- **Bezos**: Start from customer need, work backwards.
- **Jobs**: Focus = saying no to 100 other good ideas.
- **Hoffman**: Not embarrassed by v1 → launched too late.
- **Graham**: Do things that don't scale.
