# Strategic Thinking Framework

> LLM knows these frameworks. This file provides **when to apply** and **project-specific guidance**.

## Framework Selection

| Situation | Framework | Key Output |
|-----------|-----------|------------|
| Entering new market | Porter's Five Forces | Industry attractiveness + strategic implications |
| Sizing opportunity | TAM/SAM/SOM (bottom-up!) | Realistic SOM. Red flag: "If we capture 1% of $100B..." |
| Understanding users | JTBD | "When [situation], I want [motivation], so I can [outcome]" |
| Finding differentiation | Strategy Canvas (Blue Ocean) | Eliminate/Reduce/Raise/Create actions |
| Positioning | Positioning Statement | For [target] who [problem], [Product] is [category] that [benefit]. Unlike [competitors], we [differentiator]. |
| Assessing defensibility | Competitive Moat | Types: network effects, switching costs, scale, brand, proprietary tech, counter-positioning |
| Multi-dimension tradeoffs | Strategic Decision Matrix | Weights: strategic_fit 30%, market_opp 25%, competitive_adv 20%, exec_feasibility 15%, risk 10% |
| High uncertainty | Scenario Planning | 2 axes × 4 scenarios + robust strategies across multiple |
| Starting any initiative | Kill Criteria | Decide abandonment conditions in advance. Prevents sunk cost fallacy. |

## Strategic Trade-offs (Always Document)

Common: breadth↔depth, speed↔quality, growth↔profitability, customization↔scalability, innovation↔execution

Template: trade_off → our_choice → rationale → what_we_gain → what_we_lose → review_triggers

## First Principles Thinking

Use when: "everyone does it this way but why?", seems expensive for what it achieves, "industry standard"
Process: identify assumptions → break to fundamentals → rebuild
Warning: not everything needs reinventing; conventions often exist for good reasons
