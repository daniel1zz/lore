#### Palette strategy & mapping (v2)
- **Neutral**: pick ONE Tailwind family (`zinc` recommended) and stick to it everywhere.
- **Primary scale**: prefer a full scale (50–900) anchored by `primary-500`.
  - Option A (fast): use Tailwind built-in palette closest to your brand.
  - Option B (precise): generate 50–900 from one brand color (recommend OKLCH-based generation) and then verify contrast.
- **Surfaces**: define 3 levels (`background`, `surface-1`, `surface-2`, `surface-3`) to create modern depth.

**Recommended (scalable) theming**: map semantic tokens to CSS variables and swap them under `.dark`.

#### Density switching (v2)
Use a root attribute to switch density without duplicating components.

- Set on `<html>` (web) or app root (RN/UniApp adapters): `data-density="comfortable" | "compact"`
- Use Tailwind data-attribute variants: `data-[density=compact]:p-4`
- **Never** shrink interactive controls below 44px touch target.

```html
<html data-density="comfortable">
  <body>
    <div class="p-6 data-[density=compact]:p-4">
      Card content
    </div>
  </body>
</html>
```
